# Rayleigh Nails Spa Website

A 13-page responsive website built for a real, live local nail salon business, from client requirements through to full production deployment.

🔗 **Live site**: [rayleighnailsspa.co.uk](https://rayleighnailsspa.co.uk)

## About

This was freelance client work for Rayleigh Nails Spa, a local business. I managed the full client relationship independently, translating real business needs into a working, real-world product used by paying customers.

## Built With

- HTML5 / CSS3
- Tailwind CSS
- Vanilla JavaScript (no frameworks)

## Features

- Fully responsive design across desktop, tablet, and mobile
- Swipeable, keyboard-navigable image galleries
- Lightbox image viewer
- Auto-advancing carousel
- ARIA attributes throughout for accessibility
- Custom black-and-bronze-gold branding with the Fraunces typeface

## Deployment

- Hosted on **Netlify**, connected directly to this repo for continuous deployment
- Custom domain (`rayleighnailsspa.co.uk`) purchased and configured through **Cloudflare Registrar**, with DNS managed in Cloudflare and SSL provisioned automatically via Netlify/Let's Encrypt
- Images and videos compressed prior to launch, reducing total media payload by ~72% (66.5MB → 18.8MB) with no visible quality loss, using ffmpeg, Pillow, and imagequant

## Notes

This project was built with AI-assisted tooling (Cursor) as part of the development process.
